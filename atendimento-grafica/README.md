# Atendimento Gráfica

Robô de WhatsApp (simulado por enquanto), orçamento online, pedido em PDF e painel de ordens de serviço.

```bash
npm install
npm start      # painel em http://localhost:3100/admin/ e simulador em /simulador/
npm test
```

Documentação completa, roadmap e como ligar o WhatsApp real: [`../docs/atendimento-grafica.md`](../docs/atendimento-grafica.md).
